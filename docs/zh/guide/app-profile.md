# App Profile

App Profile 用于控制 SukiSU-Ultra 如何对待每一个应用：是否允许使用 root、获得 root 后以什么身份运行，以及模块对它是否可见。你可以在管理器应用中管理这些配置。

## 配置类型

每个应用处于以下三种配置状态之一：

| 类型 | 含义 |
|------|------|
| **默认** | 不做特殊处理，应用遵循全局行为。 |
| **模板** | 应用使用一组可复用的设置（*模板*），可在多个应用之间共享。 |
| **自定义** | 应用拥有独立配置，单独设置。 |

## 设置项

一份配置包含以下字段。

### 挂载命名空间

控制应用以 root 运行时所处的挂载命名空间。

- **继承**：沿用调用进程的命名空间。
- **全局**：使用全局命名空间。
- **独立**：为应用提供独立的私有命名空间。

### 用户组与权能

- **用户组**：应用进程所属的 Linux 用户组。
- **权能 (Capabilities)**：授予应用进程的 Linux 权能。

请只授予应用确实需要的权限。

### 标志

- **no_new_privs**：禁止在该 root 配置的上下文中通过 SukiSU-Ultra 进一步提升权限。

### SELinux 上下文

- **域 (Domain)**：应用进程运行所在的 SELinux 域。
- **规则 (Rules)**：为该配置额外应用的 SELinux 策略规则。

### 卸载模块

启用后，SukiSU-Ultra 会为该应用还原被模块修改过的文件。适用于不应察觉到模块改动的应用。

## 模板

模板是有名称、可复用的配置。在管理器中你可以：

- **创建**和**编辑**模板（每个模板有 ID、名称和描述）。
- **查看**模板影响了哪些应用。
- 从剪贴板**导入**模板，或将模板**导出**到剪贴板以便分享。

::: tip
如果多个应用需要相同的设置，只需创建一次模板并应用到所有应用，而不必逐个配置。
:::

::: warning
错误的用户组、权能或 SELinux 规则可能导致应用异常，或降低设备的安全性。如果出现问题，请将该应用切换回**默认**。
:::
