# 兼容性状态

::: tip GKI 2.0 设备
支持带有 GKI 2.0 内核（5.10+）的 Android 设备。你可以通过管理器以 LKM 方式安装，使用与设备 KMI 匹配的预构建模块，见 [LKM 安装](./installation#lkm-安装)。
:::

::: warning 传统内核支持
较旧的内核（4.4+）也兼容，但内核必须手动构建，见[集成指导](./how-to-integrate)。
:::

::: tip 扩展兼容性
SukiSU-Ultra 可以通过额外的反向移植支持 3.x 内核（3.4-3.18），该支持为实验性
:::

## 架构支持

目前支持以下处理器架构：

| 架构              |  支持级别   |     备注 |
|-----------------|:-------:|-------:|
| **arm64-v8a**   | ✅ 完全支持  | 主要目标架构 |
| **armeabi-v7a** | ✅ 基础支持  | 最低功能要求 |
| **X86_64**      | 🟡 部分支持 | 支持部分设备 |
