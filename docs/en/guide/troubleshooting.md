# Troubleshooting

## Device gets stuck when uninstalling the Manager app

If the device hangs while you uninstall the Manager app, uninstall `com.sony.playmemories.mobile` as well.

## Still stuck?

1. Check the [Compatibility](./compatibility) page.
2. Search or open an issue on the [GitHub repository](https://github.com/SukiSU-Ultra/SukiSU-Ultra/issues).
3. Ask in the [Telegram community](https://t.me/sukiksu).

::: tip
When reporting a problem, attach the bug report exported from the Manager app (Settings → Report log).
:::
